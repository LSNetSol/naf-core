# Contributing

Thank you for helping improve naf-core.

* Open an issue before large changes.
* Sign off every commit (`git commit -s`) to certify the Developer Certificate of Origin
  (https://developercertificate.org/).
* Add or update tests for every behavior change; `python3 -m unittest discover -s tests` must pass.
* Do not submit proprietary vendor documentation, customer data, real network topologies or
  employer-confidential material. Use synthetic data (RFC 5737 prefixes, RFC 5398 AS numbers).
* Pull requests that change the policy gate or the evidence log need two reviewers.
